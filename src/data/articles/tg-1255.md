Post-Quantum Ethereum

EF의 여러 팀이 이더리움의 양자 내성 보안 노력을 위한 전용 리소스인 [http://pq.ethereum.org](http://pq.ethereum.org) 를 출시했습니다.

2018년 초기 STARK 기반 서명 집계 연구로 시작된 이 프로젝트는 이제 여러 팀이 협력하는 오픈 소스 프로젝트로 성장했습니다.

Post-Quantum 팀과 Cryptography 팀은 Protocol Architecture 및 Protocol Coordination 팀의 지원을 받아 8년 이상 이 작업을 진행해 왔습니다.

- PQ가 각 프로토콜 계층에 미치는 영향

- 전체 PQ 로드맵 ( [http://strawmap.org](http://strawmap.org) )

- 공개 리소스: 저장소, 사양, 논문, EIP

- FAQ: PQ 팀이 작성한 5개 카테고리, 14개 질문

- 6부작으로 구성된 린 이더리움(lean Ethereum) 인터뷰 시리즈 (@zeroknowledgefm )

- 제2회 연례 PQ 리서치 리트릿(영국 캠브리지, 2026년 10월) 참가 의향서

- 이미 10개 이상의 클라이언트 팀이 PQ Interop을 통해 매주 개발넷을 구축하고 배포하고 있습니다.

모든 작업물은 공개되어 있으며 오픈 소스로 제공됩니다.
