Balaji의 Farcaster 인수는 탈중앙 소셜의 다음 챕터인가, 변질인가?

EF의 Jason Chaskin이 Balaji Srinivasan의 Farcaster 인수를 탈중앙 소셜의 다음 챕터로 반기며 '중앙화 앱이지만 탈중앙 프로토콜 위에 있어 팔로잉을 유지한 채 다른 규칙의 앱을 만들 수 있는지가 핵심'이라고 주장하자, donnoh와 다수 사용자는 '다음 챕터는 테크노 파시즘'이며 출시 첫날부터 사람들을 밴하는 것은 탈중앙과 거리가 멀다고 반발.

배경

Farcaster는 탈중앙 소셜 프로토콜로, 사용자가 특정 클라이언트 앱에 종속되지 않고 소셜 그래프(팔로잉)를 유지한 채 여러 클라이언트를 오갈 수 있게 설계됐다. Balaji Srinivasan은 Network State 개념을 제창한 인물로, 그의 인수 후 일부 사용자가 클라이언트에서 밴됐다는 불만과 로열티 서약 논란이 제기됐다.

주요 쟁점

중앙화 앱이 탈중앙 프로토콜 위에 있다는 사실이 사용자를 실제로 보호하는가(팔로잉을 유지한 채 다른 규칙의 앱으로 이탈 가능한가)

출시 첫날의 사용자 밴·로열티 서약은 '탈중앙 소셜'이라는 서사와 양립하는가
