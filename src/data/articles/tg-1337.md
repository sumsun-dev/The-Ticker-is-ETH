💰 ETH: $2,315 | 📊 ETH.D: 10.7%

⚙️ 프로토콜 업데이트

- ACDC 178차 회의에서 상호운용성 관련 주요 사항 논의됨. 합의 계층의 효율성 증대와 체인 간 연결성 강화를 목표로 함.

- 제 51차 상태 비저장 구현자 회의 개최됨. 노드가 전체 데이터를 저장하지 않고도 블록을 검증하는 기술적 진척 상황을 확인함.

- RPC 표준 회의 진행됨. 노드와 외부 애플리케이션 간의 통신 규격을 최적화하여 네트워크 운영의 안정성 향상을 도모함.

📋 EIP 동향

- EIP-7928 업데이트 제안됨. 블록 접근 인덱스를 uint16에서 uint64로 확장하여 대규모 데이터 처리 능력을 확보하고 합의 계층 명세를 구체화함.

🔬 연구 하이라이트

- 이더리움 내 표준화된 검증 프리미티브 부재 문제 분석됨. 외부 데이터와 온체인 기록 간의 독립적인 검증 체계 구축 필요성이 제기됨.

🐦 커뮤니티 논의

- VitalikButerin: 최근 발생했던 시스템 관련 기술적 이슈들이 모두 해결되었음을 알리며 네트워크 안정성을 확인해줌.

- VitalikButerin: IPFS 게이트웨이의 보안 취약성을 지적함. 중앙 집중식 게이트웨이 의존을 줄이기 위해 브라우저 차원의 직접 지원이 필요하다고 논의함.
