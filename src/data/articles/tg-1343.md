💰 ETH: $2,321 | 📊 ETH.D: 10.6%

⚙️ 프로토콜 업데이트

- FOCIL(포크 선택 독립적 포함 목록) 관련 개발 및 사양 업데이트 논의 진행중임. 검증자의 검열 저항성을 높여 네트워크 중립성을 강화하는 기술임.

- 상태 계층화(State Tiering) 제안됨. 데이터 작성 시기에 따라 상태를 관리하여 노드가 저장해야 할 데이터 용량 부담을 줄이는 방식임.

📋 EIP 동향

- ERC-8236 제안됨. 토큰 전송 시 T+2 결제 주기와 양측 합의를 도입하여 전통 금융과 유사한 거래 안정성을 확보하려는 표준임.

- ERC-3668(CCIP Read)을 위한 온체인 접근 제어 표준 논의중임. 오프체인 데이터 조회 시 특정 사용자만 접근할 수 있도록 제한하는 기능을 추가함.

- EIP-7708 업데이트됨. 전송 로그 목록에 컨트랙트 생성 정보를 포함하여 온체인 활동의 추적성과 투명성을 개선함.

- EIP-7928 업데이트됨. 블록 접근 목록의 인덱스 형식을 uint32로 변경하여 데이터 구조를 최적화하고 효율성을 높임.

- EIP-8142 업데이트됨. BiB(Block-in-Block) 구조를 모듈화하여 향후 프로토콜 변경에 유연하게 대응할 수 있도록 설계함.

🔬 연구 하이라이트

- Ara 화이트페이퍼 발표됨. 블록체인을 단순 데이터 저장소가 아닌 프로토콜 합의 및 추천 시스템으로 정의하는 새로운 패러다임을 제안함.

- 위임된 실행 샤딩(DES) 연구중임. Lean 사양과 zkEVM을 결합하여 실행 레이어의 확장성을 극대화하는 하이퍼 병렬화 기술을 탐구함.

- Lean 기반 멀티시그 스나킹 연구 진행중임. 서명 집계 대신 영지식 증명을 활용하여 보안성과 검증 효율성을 동시에 확보하려는 시도임.
