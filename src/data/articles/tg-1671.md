ZKsync, Airbender Prime, GPU 1장으로 이더리움 실시간 증명

- ZKsync가 Airbender Prime을 공개함. GPU 1장으로 이더리움 블록 실시간 증명을 시연한 첫 프루버임.

- 성능. RTX PRO 6000 1장으로 이더리움 메인넷 연속 7,200개 블록을 증명했는데, 99%가 블록당 10초 이내, 전 블록이 12초 이내에 끝남. 이더리움 블록 시간이 12초니까 블록이 나오는 속도를 증명이 따라잡은 셈.

- 오픈 표준 RISC-V 기반이고, 독립 검증기를 따로 제공해서 누구나 결과를 검증할 수 있음. 이더리움의 ZK 중심 로드맵의 핵심 부품이 될 거라는 입장.

- AI가 소프트웨어 취약점을 찾고 공격하는 속도가 빨라지는 중임. 원장 업데이트마다 ZK 증명을 요구하면, 실행 서버가 해킹당해도 규칙을 어긴 업데이트는 검증을 통과 못 함. 은행과 거래 상대방이 직접 검증할 수 있는 보안 레이어가 생기는 것임.

- GPU 1장이면 된다는 게 중요함... 증명 생성 하드웨어 요구치가 확 낮아지면 기관이나 개인 운영자도 검증 인프라를 직접 돌릴 수 있게 됨.
