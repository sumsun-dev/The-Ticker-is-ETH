⚙️ 프로토콜 업데이트

📋 EIP 동향

- EIP-8223 제안됨. 트랜잭션 발신자가 아닌 수신 계약이 가스비를 지불하는 스폰서 트랜잭션 유형임. 사전 등록된 권한 확인으로 보안을 유지함.

🔬 연구 하이라이트

- PeerDAS 성능 향상을 위해 2D 리드-솔로몬 코드 대신 블록 순환 코드를 사용하는 방안 연구됨. 인코딩과 복구 효율성을 높이는 것이 목적임.

- 저대역폭 IoT 기기를 위한 베이스드 나노 체인 제안됨. 재귀적 롤업을 통해 통신 부하를 줄이고 산업용 온체인 경제 확장을 목표로 함.

- 산업용 DAO를 위한 메타 작업증명(mPoW) 연구됨. 세이프 지갑과 임계치 암호화를 결합해 공개 감사와 데이터 프라이버시를 동시에 보호함.

- EVM 이벤트 로그 기반의 하이브리드 양자 내성 암호화 메시징 표준안 제안됨. 양자 컴퓨터 공격에 대비한 클라이언트 간 보안 통신 형식을 정의함.

- DAO 서비스 제공자(DSP) 모델 제안됨. 기존 보조금 방식에서 서비스 계약 모델로 전환하여 산업적 책임감과 인프라 지속 가능성을 높이고자 함.
